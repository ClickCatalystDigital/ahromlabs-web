title: "ASME Certification Mark (stamp)"
answer: >
  The mark a holder of an ASME certificate stamps on a boiler, pressure vessel or relief device, with a
  designator for what it is built to: U for Section VIII Division 1 vessels, S for power boilers, UV for relief
  valves.
domain: [pressure]

For a buyer it means the item was built under a quality system ASME reviewed and inspected by an Authorized Inspector, with a data report behind it. ASME replaced its 28 separate code symbol stamps with this single mark used with a designator; the old stamps for Sections I, IV, VIII, X and XII were discontinued on 31 January 2013. A supplier's certificate can be checked on ASME's Certificate Holder Search.

Every designator is in [ASME stamps](/asme/stamps); getting one is in [how to get the U stamp](/asme/u-stamp); which ones each US state requires is in [US state boiler laws](/asme/state-boiler-laws).
