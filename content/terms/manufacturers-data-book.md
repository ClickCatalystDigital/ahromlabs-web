title: "Manufacturer's data book (MDB)"
answer: >
  The bound set of quality records shipped with a pressure vessel, heat exchanger or boiler: the data report,
  drawings, MTRs, weld map, welding qualifications, NDE, heat treatment and test records, NCRs and the signed ITP.

Also called a manufacturer's record book, data dossier or turnover package. Only the [Manufacturer's Data Report](/systems/manufacturers-data-report) inside it is a Code document; the purchaser's specification sets the rest and its order. See [what goes in a data book](/asme/data-book).
